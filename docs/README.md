# Documentacion del proyecto

- `arquitectura/`: arquitectura del sistema, contexto general, catalogo de microservicios y modelo de datos.
- `contratos/`: contratos de cada microservicio (un directorio por servicio, mas coleccion de Postman).
- `decisiones/`: registro de decisiones de diseno (ADRs) y su plantilla.
- `desarrollo/`: guias para desarrollar (instalacion, Docker, convenciones, migraciones y pruebas), por escribir.
- `parciales/`: trabajos, planes y checklists por parcial. 
- `requerimentos/`: requerimientos funcionales y no funcionales, reglas de negocio, matriz de permisos y trazabilidad.
