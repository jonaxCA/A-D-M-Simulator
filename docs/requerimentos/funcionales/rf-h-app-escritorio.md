# RF-H: Aplicación de Escritorio

## Dependencias

_Sin dependencias registradas en dependencias.md._

### RF-H01 Autenticación propia

La app de escritorio debe tener su propia pantalla de login con JWT
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H02 Editor visual de escenarios

La app debe ofrecer editor gráfico de escenarios con línea de tiempo de intervenciones
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H03 Línea de tiempo

El editor debe mostrar calendario visual con barras de intervenciones superpuestas
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H04 Drag & drop de intervenciones

El usuario debe poder arrastrar intervenciones sobre la línea de tiempo
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-H05 Guardado como XML

La app debe guardar escenarios localmente en XML validado
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H06 Sincronización con servidor

La app debe poder subir/descargar escenarios del servidor
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H07 Lanzamiento por lotes

La app debe permitir seleccionar múltiples escenarios y lanzarlos todos
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H08 Cola de trabajos visible

La app debe mostrar lista de trabajos en cola, ejecutando y completados
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H09 Descarga de resultados

La app debe descargar resultados completos para análisis offline
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-H10 Comparador visual

La app debe permitir superponer curvas de múltiples escenarios
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H11 Frontera de eficiencia

La app debe graficar frontera de Pareto localmente
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-H12 Mapa 2D local

La app debe mostrar mapa de incidencia por zona
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-H13 Generación de reportes

La app debe generar reportes PDF/imprimibles
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-H14 Registro de operaciónes

La app debe mantener bitácora local de actividades
Criterio de aceptación: pendiente de definir
Prioridad: Baja

### RF-H15 Notificaciones

La app debe notificar en escritorio cuando una corrida termina
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-H16 Trabajo offline

La app debe permitir editar escenarios sin conexión y sincronizar después
Criterio de aceptación: pendiente de definir
Prioridad: Baja
