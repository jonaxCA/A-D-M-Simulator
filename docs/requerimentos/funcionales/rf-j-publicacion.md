# RF-J: Publicación y Comunicación

## Dependencias

_Sin dependencias registradas en dependencias.md._

### RF-J01 Sitio público

El sistema web debe ofrecer sitio sin autenticación con información general
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-J02 Escenarios publicados

El sitio público debe mostrar escenarios marcados como publicados con sus supuestos
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-J03 Indicadores agregados

El sitio público debe mostrar indicadores agregados sin datos sensibles
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-J04 Leyenda académica

Toda publicación debe incluir aclaración de que es proyecto académico
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-J05 Supuestos visibles

Todo escenario publicado debe acompañarse de sus supuestos y limitaciones
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-J06 Notas de versión

El sistema debe mostrar cambios relevantes entre versiones de datos
Criterio de aceptación: pendiente de definir
Prioridad: Baja

### RF-J07 Comunicación de incertidumbre

Las gráficas públicas deben mostrar banda de incertidumbre, nunca curva única
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-J08 Exportación para prensa

El sistema debe generar gráficas en alta resolución para comunicación pública
Criterio de aceptación: pendiente de definir
Prioridad: Baja
