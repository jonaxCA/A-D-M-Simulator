# RF-L: Administración del Sistema

## Dependencias

_Sin dependencias registradas en dependencias.md._

### RF-L01 Gestión de usuarios

El administrador debe poder crear, editar, desactivar y eliminar usuarios
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-L02 Asignación de roles

El administrador debe poder cambiar roles de usuarios
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-L03 Gestión de dispositivos

El sistema debe permitir revocar acceso a dispositivos móviles específicos
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-L04 Gestión de sesiónes

El administrador debe poder forzar cierre de sesiónes activas
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-L05 Consulta de auditoría

El administrador debe poder consultar bitácora de auditoría con filtros
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-L06 Configuración global

El administrador debe poder modificar parámetros del sistema (umbrales, límites)
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-L07 Gestión de almacenamiento

El administrador debe poder gestionar archivos en Cloud Storage
Criterio de aceptación: pendiente de definir
Prioridad: Baja

### RF-L08 Copia de respaldo

El sistema debe permitir programar respaldos automáticos de PostgreSQL
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-L09 Restauración

El sistema debe permitir restaurar desde respaldo
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-L10 Mantenimiento programado

El sistema debe permitir entrar en modo mantenimiento con aviso a usuarios
Criterio de aceptación: pendiente de definir
Prioridad: Baja
