# RF-G: Tablero de Control (Sistema Web)

## Dependencias

- RF-C (datos de vigilancia)
- RF-F (resultados de simulación)

### RF-G01 Tablero principal

El sistema web debe mostrar indicadores epidemiológicos clave en tiempo real
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G02 Gráficas interactivas

El sistema debe usar Highcharts para visualización interactiva (zoom, tooltip, filtros)
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G03 Mapa de calor

El sistema debe mostrar mapa de incidencia por zona con escala de color
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G04 Filtros temporales

El usuario debe poder filtrar por período: últimos 7, 30, 90 días, personalizado
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G05 Filtros geográficos

El usuario debe poder filtrar por municipio, AGEB o corredor
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G06 Filtros demográficos

El usuario debe poder filtrar por grupo etario y sexo
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-G07 Indicadores de capacidad

El tablero debe mostrar ocupación hospitalaria actual y tendencia
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G08 Alertas por umbral

El sistema debe mostrar alertas cuando indicadores superan umbrales configurados
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G09 Actualización automática

El tablero debe actualizarse sin recarga completa (AJAX/polling)
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-G10 Responsive design

El tablero debe ser legible en dispositivos móviles
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-G11 Acceso por rol

El tablero debe mostrar más detalle a usuarios con más permisos
Criterio de aceptación: pendiente de definir
Prioridad: Alta

### RF-G12 Exportación desde tablero

El usuario debe poder exportar vista actual como imagen o PDF
Criterio de aceptación: pendiente de definir
Prioridad: Media

### RF-G13 Widgets configurables

El usuario debe poder personalizar qué indicadores ve en su tablero
Criterio de aceptación: pendiente de definir
Prioridad: Baja

### RF-G14 Modo comparación

El tablero debe permitir mostrar resultados de simulación junto a datos reales
Criterio de aceptación: pendiente de definir
Prioridad: Alta
